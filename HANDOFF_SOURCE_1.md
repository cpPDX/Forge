## src/world/World.js

Key signatures:

```js
export class World {
  constructor(seed)             // creates 7 noise functions, surface cache
  getTile(tx, ty)               // returns tile ID; lazy chunk generation
  setTile(tx, ty, id)           // sets tile; marks chunk dirty
  isSolid(tx, ty)               // delegates to TileRegistry
  getSurfaceHeight(tx)          // cached surface Y for column tx
  getBiome(tx)                  // BIOME.FOREST/DESERT/SNOW/JUNGLE
  moveAndCollide(px,py,pw,ph,mvx,mvy,dt)  // AABB physics; returns {x,y,vx,vy,onGround,onCeiling,onWall}
  getSpawnPoint()               // returns {x,y} at world center surface
}
```

World generation layers (by tile Y):
- `ty >= WORLD_HEIGHT - 3` → BEDROCK
- `ty < surfY` → AIR
- `ty >= LAYER.CAVERN_BOTTOM` → Underworld (Hellstone/Lava/Netherrack)
